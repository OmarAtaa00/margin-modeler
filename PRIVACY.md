# Privacy Notice Last updated: 2026-07-31 ## Overview Margin Modeler is a browser-based project planning and margin-modeling application. The current application uses Supabase for user authentication and authenticated cloud workspace persistence. ## Account information Users authenticate using an email address and password through Supabase Authentication. Authentication data is processed and stored through the configured Supabase project. Password handling is performed by Supabase Authentication and is not implemented or stored directly by Margin Modeler. ## Workspace data Workspace information may include: - Project and scenario names - Resource or role names - Project and assignment dates - Cost rates - Bill rates - Allocation percentages - Direct hours - Calculated project costs - Calculated revenue - Calculated margins Authenticated workspace data is stored in the Supabase `projects` table.
